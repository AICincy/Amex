# Staff contributions

Use GitHub Issues. Do not paste unpublished numeric floors into an issue title or body.

| Template | Use |
| --- | --- |
| AutoMod change | Request a YAML draft change |
| Live behavior | Something AutoMod did or failed to do on r/amex |
| Paste record | Record that a human gate was completed |

YAML edits go in `automod/current/` only. The owner authorizes version bumps.
