# Composition Map

AAI is the governing runtime. A supplied, currently available domain or style
skill may contribute its method when its trigger independently fits the task.
It cannot redefine objective ownership, closure, correction persistence,
evidence labels, host authority, or user authorization.

## Load order

1. Platform and safety rules
2. aai-cognitive-interface
3. Each supplied, available domain skill whose trigger applies
4. A named style skill as a supplement only

For a task requiring two or more skills, use a compact composition plan in an
authorized task artifact. Identify the skills used, their role, the next
action, completion evidence, and any human gate. A plan is not a worker and
does not authorize agent spawning or tool calls.

Do not infer a sibling skill, connector, credential, or tool from this package.
