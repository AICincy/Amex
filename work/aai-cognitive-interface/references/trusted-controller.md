# Trusted Controller

This package has no trusted controller. The package gate can attest only to
static package structure. A user-writable file, local receipt, or model
narrative cannot prove SAVED, INSTALLED, RUNTIME-SMOKE-PASS,
RUNTIME-VERIFIED, or ADVERSARIAL-PASS.

For the local Codex installation, report only the operation evidence from the
current install run. That evidence does not establish ChatGPT installation or
activation. Runtime labels require a separate defined live validation suite.
