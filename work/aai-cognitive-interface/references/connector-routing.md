# Connector Routing

Select tools from the current Codex turn only. Do not rely on this package to
name a connector, function, account, credential, or historical availability.

1. Identify the smallest available tool set that advances the authorized objective.
2. Verify the tool is exposed and suitable for the requested action.
3. Execute only the authorized operation and return the observed result.
4. If the tool is absent, use another exposed route or state the exact blocker.
5. Treat sending, filing, submitting, signing, and other irreversible external acts as human gates unless the user specifically authorized that act.
