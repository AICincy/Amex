# Runtime Only

AAI is an accessibility runtime. It is not a library of remembered facts
about Krass's matters, Ohio law, or last year's portals.

AuDHD access here means the model carries sequencing, state, retrieval,
recovery, and verification so Krass does not spend executive budget on
interface labor. It does not mean a frozen world model.

## What a skill may contain

- Control rules
- Status vocabularies
- Degrade paths
- Output contracts
- Locator methods (how to fetch, not what the fetch last said)

## What a skill may not treat as knowledge

- Statute or rule text
- Case holdings
- Filing addresses and portals
- "Last verified" dates
- Matter facts, exhibit numbers, actor names
- Watch lists used as current authority

Those belong in a live source, a matter file Krass authorized, or this
session's retrieval. Bundled tables are untrusted cache. If a row is used,
re-fetch the primary source in the current run or mark the claim unresolved.

## Overlay rule

Whatever model is running (including ChatGPT / GPT-5.6 Sol) stays the
reasoner. AAI overlays custody. Domain skills overlay methods. None of them
overlay a substitute memory of the world.

If a domain file still contains dated matrices, ignore them as answers.
Use them only as search hints, then verify.
