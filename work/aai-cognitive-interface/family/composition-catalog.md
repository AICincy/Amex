# Composition Catalog

AAI is the governor. Apply a subordinate skill only when the user supplied it,
it is available in the current Codex turn, and its trigger independently fits
the request. Do not infer or install sibling skills from this catalog.

For a multi-skill task, record a composition plan outside this package using
the current host's authorized artifact workflow. The plan is a coordination
record, not an instruction to spawn agents or invoke unavailable tools.
