## Viewpoint-restriction checklist

Use only when the authorized source set supports a state-action theory.

1. Identify whether the account is an official agency account or a personal account.
2. State the forum type from the record, not from this skill.
3. Identify the restriction: total closure, selective removal, or pre-screening.
4. If alleging viewpoint discrimination, put the pattern in a table.
5. Re-fetch any cited case or constitution section this session.
