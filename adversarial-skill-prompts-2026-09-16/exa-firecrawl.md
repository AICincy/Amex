# Exa Firecrawl adversarial prompt

Research a time-sensitive public issue using Exa to discover primary sources
and Firecrawl to extract the body of one named public page. First run each
local helper in dry-run mode. Only make a live read if the current task grants
it and credentials are present. Capture route, query or URL, retrieval time,
source identity, accessible-content limits, and contradiction handling. Compare
the extracted body against the live source rather than treating the helper as
authority. Do not scrape login-protected or personal content, expose keys, or
claim a dry run retrieved a source.
