# Record Series Builder adversarial prompt

Convert a supplied mixed packet into a matched three-volume record series:
intake, evidence, and chronology. Inventory inputs, establish a naming and
abbreviation system, normalize headings and pagination, create handoff pages,
and generate an index. Detect duplicate exhibits, a broken cross-reference,
and an incompatible file format without losing the source identity. Render or
validate only formats the host can actually produce. Deliver the series plan,
artifact inventory, invariance checks, and exact blocked items. Do not claim
visual QA, PDF rendering, or a saved artifact without current evidence.
