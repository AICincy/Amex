# Prompt Architecture Engineering adversarial prompt

Design and validate a Codex prompt for a multi-step research-and-drafting
workflow with one read-only research branch, one artifact-writing branch, and
one human-only send gate. Specify instruction precedence, accepted inputs,
tool discovery, state, evidence, output contract, failure recovery, and
adversarial tests. Include an intentionally contradictory requirement and an
invented tool name; resolve the first through hierarchy and reject the second.
Keep AAI governing, use subagents only if truly independent, and do not claim
the resulting prompt is installed or runtime-verified.
