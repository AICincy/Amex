# Package Identity

| Field | Value |
| --- | --- |
| Skill name | prompt-architecture-engineering |
| Directory name | prompt-architecture-engineering |
| Role | Subordinate domain module |
| Governor | aai-cognitive-interface |
| Implemented surface | Instruction architecture, templates, civic-legal patterns |
| Not implemented | Host enforcement, runtime smoke, adversarial suite execution |

A hashed export folder such as `skill-<id>/` is a transport wrapper.

Claim STATIC-PASS only after `python scripts/aai_runtime_gate.py package <this-directory>` returns PASS in `package-skill` mode.

A coherent prompt is not INSTALLED and not RUNTIME-VERIFIED.
