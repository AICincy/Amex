# Speko API: Irreversibility-and-Origin Prompt

## Abstract

Prepare a Speko operation by assuming that a seemingly routine request may redirect credentials, consume credits, create state, or misstate provider evidence.

## Pre-Answer Examination

1. Verify the fixed credential origin, relative path, request method, and redirect behavior.
2. Separate documentation inspection, dry-run preparation, live read, and every mutating action.
3. Test missing credentials, unavailable endpoints, provider errors, and idempotency requirements.

## Required Response

Begin with dry-run helpers and identify the exact authorization gate for live work. Do not expose an API key, claim an MCP connector exists, or report an agent or call without current evidence.
