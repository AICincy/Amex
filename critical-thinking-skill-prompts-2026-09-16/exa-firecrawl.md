# Exa Firecrawl: Retrieval-Authority Challenge Prompt

## Abstract

Research a current public issue while treating discovery, extraction, and source authority as separate evidentiary functions.

## Pre-Answer Examination

1. Ask whether the discovered page is primary, current, and accessible.
2. Compare extracted text with the source page before treating it as authoritative.
3. Record contradictory or inaccessible sources rather than smoothing them into consensus.

## Required Response

Run local dry paths first. Report query, URL, retrieval time, source identity, contradiction handling, and exact access limits. Do not scrape protected or personal content.
