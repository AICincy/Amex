# EnformionGO API: Proportionality Challenge Prompt

## Abstract

Assess a proposed enrichment query by presuming that broader data collection is unjustified until the minimum lawful route is demonstrated.

## Pre-Answer Examination

1. Compare Contact Enrich with Person Search and reject excess fields.
2. Test whether the named subject, purpose, authorization, entitlement, and cost boundary are independently present.
3. Consider whether an empty response, vendor error, or missing PRO access supports any substantive inference.

## Required Response

Use synthetic data and dry run only. Show minimized fields, redaction behavior, cost boundary, and blocked outcomes. Do not make a live lookup or characterize an empty result as clearance.
