# Register Mediation: Intent-Preservation Prompt

## Abstract

Recover an interrupted authorized task by assuming that a change in tone could either preserve intent or improperly launder a prohibited action.

## Pre-Answer Examination

1. Preserve the parked objective, constraints, evidence, and next action.
2. Test whether the requested form rewrite changes authorization or technical substance.
3. Differentiate a recoverable host interruption from a substantive prohibition.

## Required Response

Produce one safe retry form and return to the parked objective. State the exact prohibited boundary when present. Do not loop retries or use softer language to bypass safeguards.
